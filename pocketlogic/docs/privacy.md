# Privacy Policy – Pocket Logic Uploader

*Last updated: 6 October 2026*

Pocket Logic Uploader ("the app") is a private tool used only by the owner of the YouTube channel
"Pocket Logic" to upload the channel's own videos. This policy explains what data the app accesses.

## Use of YouTube API Services
The app uses **YouTube API Services**. By using the app you agree to be bound by the
[YouTube Terms of Service](https://www.youtube.com/t/terms). Google's handling of your data is
described in the [Google Privacy Policy](https://policies.google.com/privacy).

## Data the app accesses
With the channel owner's permission (Google OAuth), the app requests:

| Permission | Purpose |
|---|---|
| `youtube.upload` | Upload the channel's own videos, set their title, description, tags and scheduled publish time |
| `youtube.readonly` | Read the channel name and the status of videos the app uploaded (e.g. whether a video is scheduled or private) |

The app does **not** access viewers' data, comments, subscribers, analytics, or any other account.

## Storage
- The OAuth refresh token is stored only on the owner's private server, readable only by the
  owner's user account, and is used solely to perform the uploads described above.
- Video IDs and upload status are kept in a local log on that server for the owner's own reference.
- No data is sold, shared with or transferred to third parties. Data is only exchanged with
  Google/YouTube to perform the uploads.

## Limited Use
The app's use and transfer of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.

## Retention and deletion
Local logs are deleted automatically after a limited time. Access can be revoked at any time at
[Google account permissions](https://myaccount.google.com/permissions) or via
[Google security settings](https://security.google.com/settings/security/permissions);
after revocation the stored token no longer works and is deleted by the owner.

## Contact
Questions about this policy can be sent through the contact options on the
Pocket Logic YouTube channel.
